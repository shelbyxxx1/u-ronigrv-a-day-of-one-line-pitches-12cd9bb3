# A Day of One-Line Pitches

Entry for the make.fun bounty
[A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3):
a program that writes one sentence to `/output/entry.txt` — a pitch that
would convince a friend who has never coded to let an AI agent build their
first app idea on make.fun.

## Run

```sh
python3 main.py
```

With no `MAKEFUN_OUTPUT_DIR` set it writes to `/output/entry.txt`
(the grader's mount). Standard library only, no network, no secrets.

## The pitch

> Just describe your idea in plain words on make.fun and you'll have a
> working first app to try — free to build, and free to change with one
> more sentence.

One sentence, 153 characters — inside the gate's 1–240 characters.
